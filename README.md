# Scientific Calculator 🧮

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

A fully responsive scientific calculator built with vanilla HTML, CSS, and JavaScript. It supports a wide range of mathematical operations, keyboard input, and features a clean, modern user interface.



---

## Features

* **Standard Arithmetic**: Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
* **Scientific Functions**:
    * Trigonometric: `sin`, `cos`, `tan`
    * Logarithmic: `ln`, `log` (base 10)
    * Powers & Roots: `x^y`, `√`
    * Factorial (`!`) and Parentheses `()`
* **Constants**: Pi (`π`) and Euler's number (`e`).
* **Angle Mode Toggle**: Switch between **Degrees (DEG)** and **Radians (RAD)** for trigonometric calculations.
* **Fully Responsive Design**: The layout adapts seamlessly to any screen size, from mobile phones to desktop monitors.
* **Keyboard Input**: Perform calculations using your physical keyboard for a faster workflow.
* **Modern UI**: A clean and intuitive "Neumorphic" (soft UI) design.

---

## Technologies Used

* **HTML5**: For the structure and content of the calculator.
* **CSS3**: For styling, layout (Grid), and responsiveness. Uses custom properties for easy theming.
* **Vanilla JavaScript**: For all the logic, calculations, and event handling without any external libraries.

---

## How to Use

No installation or setup is required.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/scientific-calculator.git](https://github.com/your-username/scientific-calculator.git)
    ```
2.  **Navigate to the folder:**
    ```bash
    cd scientific-calculator
    ```
3.  **Open the `index.html` file** in your favorite web browser.

That's it! The calculator is ready to use.

---

## Keyboard Shortcuts

You can control the entire calculator using your keyboard:

| Key             | Function                 |
| :-------------- | :----------------------- |
| `0-9`           | Enters the corresponding number |
| `+` `-` `*` `/` | Enters the corresponding operator |
| `.`             | Enters a decimal point   |
| `Enter` or `=`  | Calculates the result    |
| `Backspace`     | Deletes the last entry (`<`) |
| `Escape`        | Clears the entire display (`AC`) |
| `(` `)` `^` `%` | Enters the corresponding symbol |
